## 我修改了哪些内容

在原始示例程序基础上，我进行了以下个性化修改：

1. **标签页标题 & AppBar 标题**：改为"创新实验 Flutter 首页"，AppBar 配橙金色背景 + 火焰图标
2. **主题色**：将 indigo 蓝改为橙金色系（`Color(0xFFFF8C00)`），整体视觉温暖活力
3. **渐变背景**：body 采用三色暖色渐变（奶黄 → 橙红 → 白橙），替换默认白底
4. **信息卡片**：新增小组、本周任务信息行
5. **计数器改为卡片式布局**：打卡次数以大号数字显示在深橙渐变卡片中，字体 52px
6. **动画效果**：
   - 头像区域呼吸脉冲动画（ScaleTransition，1.0→1.10 循环）
   - 打卡数字弹跳动画（elasticOut）
   - 进度条 TweenAnimationBuilder 平滑过渡
7. **进度条 + 里程碑系统**：今日进度条带百分比，⚡3次 / 🔥6次 / 🏆10次 三档里程碑
8. **激励文字 + 等级图标**：4 档随打卡次数变化（🌱→⚡→🔥→🏆），文案同步更新
9. **技能徽章区**：新增 5 个图标徽章（入门/编程/移动端/协作/创新）
10. **重置按钮**：打卡后出现重置按钮，可重新开始
